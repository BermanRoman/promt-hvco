# HVCO с проверкой результата

Корень библиотеки находится на три уровня выше этого файла.

Прочитай [hvco.md](../../../hvco.md), сначала выбери режим и подключи только его разделы по таблице маршрутов.

Один документ с нужными разделами достаточен, модельный CustDev остаётся гипотезой.

Следуй применимому маршруту [процесса](../../../workflow.md): при новом полном написании каркас и его действующее согласование предшествуют чистовику.

Пиши от лица клиента мечты, не подключай автоматически голос Романа, Гусара или персону Васьки.

Полный текст проходит редактора и отдельного [целевого читателя](../../../roles/target-reader.md), которого выбирают по сегменту; точная короткая правка выполняется ведущим с проверкой диффа.

Сохраняй состояние и границы полномочий; готовность текста не разрешает публикацию или отправку клиентам.
