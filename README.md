# HVCO

Мастер-промпт превращает исследование конкретной аудитории в историю от первого лица клиента мечты с двумя эпифаниями и пользой, которую можно применить без покупки.

Методика сохраняет Invisible Funnel, Epiphany Bridge и восемь секций: Backstory, Desire, The Wall, Epiphany, Plan, Result, Moral, CTA.

## Как начать

Открой [hvco.md](hvco.md) и передай исследование, сведения о продукте, фактуру героя и действие, к которому нужно привести читателя.

Одна база знаний со всеми нужными разделами подходит, отдельные семь файлов не требуются.

Примеры задач:

- «Собери каркас HVCO по этой базе, в финале ведём на скачивание таблицы; сначала покажи стратегию».
- «Каркас согласован, напиши весь текст от лица выбранного клиента и проведи отдельную читательскую проверку».
- «Проверь готовый HVCO, исходник не меняй».
- «Исправь только переход к продукту, сохрани факты и утверждённый CTA».

Если работаешь в чате без доступа к файлам, передай также документы, на которые ссылается мастер-промпт, либо загрузи библиотеку в проект целиком.

Для агентной среды точка входа — [.agents/skills/hvco-loop/SKILL.md](.agents/skills/hvco-loop/SKILL.md), она использует файлы полного клона.

## Как проходит работа

Исследование → каркас и его согласование → полный черновик → проверка фактов и реализации → отдельный целевой читатель → адресные исправления → приёмка актуальной версии.

Рассказчик говорит языком выбранного сегмента, голос Романа и персона Васьки из других проектов сюда не подставляются.

По умолчанию текст выдаётся целиком, по секциям — по выбору пользователя.

| [references/methodology.md](references/methodology.md) | Предметная методика и редакторские проверки |

## Зависимости

Исходный [prompt-audience-research](https://github.com/BermanRoman/prompt-audience-research) собирает базу знаний, которую использует HVCO.

В проверенной версии его CustDev включает ответы модели от лица клиента, поэтому такие сведения учитываются как гипотезы, а не как реальные интервью.

Реальная история, цитата и результат клиента требуют соответствующих источников; составная или учебная история обозначается в самом материале.

Опциональный журнал версий берётся из [promt-copywriting](https://github.com/BermanRoman/promt-copywriting), без копирования его кода, авторского голоса и ролей читателя.

Версии источников закреплены в [dependencies.json](dependencies.json), настройка и ограничения описаны в [docs/dependencies.md](docs/dependencies.md).

```sh
python3 scripts/check_dependencies.py
python3 -m unittest discover -s tests -v
git diff --check
```

Требуются Python 3.9+ и Git, дополнительные пакеты и API-ключи не нужны.

Без соседних клонов можно работать по документам вручную, проверка checkout нужна для подтверждения закреплённых зависимостей.

## Границы результата

Полная готовность включает текущие данные, утверждённый каркас, проверенный текст и отсутствие блокеров, один статус журнала её не доказывает.

Реакция модельного читателя помогает проверить понимание, но не измеряет конверсию реальной аудитории.

Публикация, рассылка, реклама и сбор контактов выполняются только по соответствующему поручению.

Изменения и проверка переноса описаны в [docs/migration.md](docs/migration.md).
